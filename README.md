## Core Mechanics and Implemented Rules

Web-based territory control game.

1. **Garrison Rule:** Attackers leave exactly 1 troop behind in their home territory after a successful capture.
2. **Combat Ties:** Cide roll ries result end up in 0 losses for both the attacker and defender.
3. **AI Logic:** The NPC dynamicall targets the weakest player-owned country using its strongest available territory.
4. **Anti-Soft-Lock:** The starting player receives a commanders bonus ensuring a minimum of 3 starting soldiers to ensure an actionale first turn.
